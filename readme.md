# 🚀 Cómo Ejecutar los Proyectos

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/mramirezcc/LabSD.git
```

---

## 2️⃣ Ingresar al proyecto

```bash
cd LabSD
```

---

## 3️⃣ Ejecutar laboratorio

Ejemplo:

```bash
cd Lab03/ejercicio_propuesto/python
python server_gui.py
```

En otra terminal:

```bash
python client_gui.py
```

- Simular comportamiento de nodos distribuidos.
