Análisis técnico — Limitaciones SOAP desde navegador
¿Por qué SOAP tiene limitaciones en consumo directo desde el navegador?

1. Política CORS (Cross-Origin Resource Sharing): Los navegadores bloquean peticiones XMLHttpRequest / fetch a dominios distintos al origen de la página, a menos que el servidor responda con el header Access-Control-Allow-Origin. Los servicios SOAP antiguos raramente incluyen estos headers.

2. Formato XML complejo: Construir y parsear el envelope SOAP desde JavaScript puro requiere manipulación de DOM XML que es verbose y propensa a errores, a diferencia de JSON en REST.

3. Ausencia de librerías nativas: El navegador no incluye un cliente SOAP nativo; se necesitan librerías externas como soap.js o proxies intermedios.

Solución recomendada: Usar un backend intermediario (Node.js / Python con Zeep) que consuma el servicio SOAP y exponga una API REST al frontend.
